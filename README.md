# 翻滚吧，艾改错！

16 关纯静态单机网页游戏。直接打开即可玩，无账号、排行榜或服务器依赖。

- 方向键 / WASD，手机直滑或点击大方向键。
- 站立落入黄色方洞通关；橙色薄板不能站立。
- 逐关解锁，支持撤销、失败重试和投降答案演示。
- 后八关最短解为 15、18、24、26、32、34、41、46 步。
- 进度保存在当前浏览器，不跨设备同步。

## 发布
在 Settings → Pages 中选择 Deploy from a branch，分支 main，目录 / (root)，点击 Save。
发布完成后的地址：https://iso9001liu-sketch.github.io/aigaicuo-roll/

## 离线游玩
下载仓库 ZIP 并解压，在支持 WebGL 的浏览器中打开 index.html。
